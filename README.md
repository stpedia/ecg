# ADS1293 (CJMCU-1293) ECG Module with NodeMCU ESP8266
### پشتیبانی از MicroPython و Arduino C++

پروژه کامل راه اندازی سنسور ECG مدل ADS1293 (CJMCU-1293) با استفاده از میکروکنترلر NodeMCU ESP8266 به دو زبان **MicroPython** و **Arduino C++**.

این پروژه امکان دریافت و رسم همزمان **۳ لید استاندارد ECG** شامل:
- **Lead I** (دست راست تا دست چپ: $LA - RA$)
- **Lead II** (دست راست تا پای چپ: $LL - RA$)
- **Lead III** (دست چپ تا پای چپ: $LL - LA$)

را روی **Serial Plotter** (از طریق پورت USB / Serial) فراهم می‌سازد.

## ❓ علت خروجی `Lead1:0.000, Lead2:0.000, Lead3:0.000` و راه کارهای حل آن

اگر در خروجی سریال مقدار ثابت `0.000` دریافت می‌فرمایید، به دلایل فنی زیر است:

### ۱. قطعی یا اشتباه در سیم‌کشی SPI بین NodeMCU و ADS1293
هنگامی که پروتکل SPI متصل نباشد یا متصل باشد اما داده‌ای منتقل نشود، مقدار صفر ثبت می‌شود.
- **تست سریع:** در اجرای کد `main.py` اگر پیغام `WARNING: SPI communication issue detected!` را مشاهده کردید، اتصال پایه CS یا SDO/SDI اشتباه است.
- **پایه‌ها را مجدداً چک کنید:**
  - `D8 (GPIO15)` -> `CS`
  - `D5 (GPIO14)` -> `SCLK`
  - `D6 (GPIO12)` -> `SDO` (MISO)
  - `D7 (GPIO13)` -> `SDI` (MOSI)
  - `3V3` -> `3V3`
  - `GND` -> `GND`

### ۲. اتصال کابل جک ۳.۵ میلی‌متری و الکترودها روی بدن
سنسورهای 24-بیتی ECG مانند ADS1293 بسیار حساس هستند. اگر الکترودها روی بدن نچسبیده باشند یا کابل متصل نباشد، خروجی صفر یا نویز نامفهوم خواهد بود.

## 🎧 نحوه اتصال دقیق کابل‌های ECG به ماژول و بدن

برای کابل‌های ۳ سیمه ECG با جک ۳.۵ میلی‌متری و الکترودهای چسبی دکمه‌ای (Snap Electrodes):

### ۱. اتصال جک به برد
- جک ۳.۵ میلی‌متری کابل را به سوکت مشکی‌رنگ روی ماژول **CJMCU-1293** وارد کنید.

### ۲. نحوه اتصال ۳ گیره رنگی (Red, Yellow, Green) به بدن:

| رنگ گیره کابل | کانال مربوطه روی ADS1293 | نقش آناتومیک | محل اتصال روی بدن |
|--------------|-------------------------|-------------|------------------|
| **قرمز (Red)** | **IN2 (RA)** | **Right Arm** (دست راست) | زیر ترقوه راست یا روی مچ دست راست |
| **زرد (Yellow)** | **IN1 (LA)** | **Left Arm** (دست چپ) | زیر ترقوه چپ یا روی مچ دست چپ |
| **سبز (Green)** | **IN3 (LL / RLD)** | **Left Leg / Reference** (پای چپ / زمین مرجع) | پایین شکم سمت چپ یا مچ پای چپ |

## 🔌 جدول اتصالات پایه به پایه (Wiring Diagram)

| پایه ADS1293 | پایه NodeMCU ESP8266 | توضیح |
|-------------|----------------------|-------|
| **3V3 / VCC** | **3V3** | تغذیه ۳.۳ ولت |
| **GND** | **GND** | زمین مشترک |
| **CS / Chip Select** | **D8 (GPIO15)** | انتخاب تراشه SPI |
| **SCLK / SCK** | **D5 (GPIO14)** | کلاک SPI (HSPI) |
| **SDO / MISO** | **D6 (GPIO12)** | خروجی داده SPI |
| **SDI / MOSI** | **D7 (GPIO13)** | ورودی داده SPI |
| **DRDYB / DRDY** | **D1 (GPIO5)** | سیگنال آماده بودن داده |

## 🚀 نحوه اجرای برنامه و رسم نمودار

### روش ۱: استفاده از MicroPython
1. فایل‌های `ads1293.py` و `main.py` را با نرم‌افزار Thonny روی NodeMCU آپلود کنید.
2. اسکریپت `main.py` را اجرا کرده و در Serial Plotter نمودارها را ببینید.

### روش ۲: استفاده از آردوینو (Arduino C++)
1. نرم‌افزار **Arduino IDE** را باز کرده و پشتیبانی از برد ESP8266 را نصب کنید.
2. فایل `ADS1293_ECG.ino` را باز کنید.
3. برد را روی **NodeMCU 1.0 (ESP-12E Module)** بگذارید و برنامه را آپلود کنید.
4. از مسیر `Tools -> Serial Plotter` یا `Tools -> Serial Monitor` (با Baud Rate 115200) نمودار را مشاهده نمایید.
