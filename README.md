# ADS1293 (CJMCU-1293) ECG Module with NodeMCU ESP8266 (MicroPython)

پروژه راه اندازی سنسور ECG مدل ADS1293 (CJMCU-1293) با استفاده از میکروکنترلر NodeMCU ESP8266 به زبان میکروپایتون (MicroPython).

این پروژه امکان دریافت و رسم همزمان **۳ لید استاندارد ECG** شامل:
- **Lead I** (دست راست تا دست چپ: $LA - RA$)
- **Lead II** (دست راست تا پای چپ: $LL - RA$)
- **Lead III** (دست چپ تا پای چپ: $LL - LA$)

را روی **Serial Plotter** (از طریق پورت USB / Serial) فراهم می‌سازد.

---

## 🔌 جدول اتصالات (Wiring Diagram)

اتصال بین ماژول **CJMCU-1293 (ADS1293)** و پایه های **NodeMCU ESP8266**:

| پایه ADS1293 | پایه NodeMCU ESP8266 | توضیح |
|-------------|----------------------|-------|
| **3V3 / VCC** | **3V3** | تغذیه ۳.۳ ولت |
| **GND** | **GND** | زمین مشترک |
| **CS / Chip Select** | **D8 (GPIO15)** | انتخاب تراشه SPI |
| **SCLK / SCK** | **D5 (GPIO14)** | کلاک SPI (HSPI) |
| **SDO / MISO** | **D6 (GPIO12)** | خروجی داده SPI |
| **SDI / MOSI** | **D7 (GPIO13)** | ورودی داده SPI |
| **DRDYB / DRDY** | **D1 (GPIO5)** | سیگنال آماده بودن داده |

---

## 🩺 اتصالات الکترودهای سیگنال ECG (3-Lead Electrodes)

| پایه روی ماژول ADS1293 | اتصال الکترود | موقعیت آناتومیک |
|----------------------|--------------|----------------|
| **IN1** | **LA** (Left Arm) | بالای سینه سمت چپ / زیر ترقوه چپ |
| **IN2** | **RA** (Right Arm) | بالای سینه سمت راست / زیر ترقوه راست |
| **IN3** | **LL** (Left Leg) | پایین سینه / سمت چپ شکم |
| **IN4** | **RLD / RL** (Right Leg Drive) | مرجع بیوپتانسیل / سمت راست شکم |

## 🚀 نحوه راه‌اندازی و استفاده

1. **نصب MicroPython روی NodeMCU:**
   در صورت عدم نصب، آخرین فریم‌ور MicroPython برای ESP8266 را دانلود کرده و با `esptool` روی NodeMCU بفلشید.

2. **انتقال فایل‌ها:**
   فایل‌های `ads1293.py` و `main.py` را با نرم‌افزارهایی مثل **Thonny IDE** یا `ampy` روی NodeMCU ESP8266 آپلود کنید:
   - در Thonny IDE، هر دو فایل را باز کرده و در حافظه میکرو (MicroPython device) ذخیره نمایید.

3. **رسم نمودار روی Serial Plotter:**
   - **روش ۱: Arduino IDE Serial Plotter**
     در نرم‌افزار Arduino IDE به مسیر `Tools -> Serial Plotter` بروید. Baud Rate را روی **115200** تنظیم کنید.
   - **روش ۲: نرم‌افزار SerialPlot**
     برنامه SerialPlot را اجرا کرده، پورت سریال NodeMCU را انتخاب و با Baud Rate 115200 متصل شوید تا ۳ نمودار لید به همراه راهنما به صورت زنده نمایش داده شوند.

## ⚡ خروجی سریال

فرمت ارسال داده‌ها روی پورت سریال به شکل زیر است:
```text
Lead1:0.125,Lead2:0.410,Lead3:0.285
```
نرم‌افزارهای سریال پلاتر به‌طور خودکار مقادیر `Lead1`، `Lead2` و `Lead3` را به تفکیک رنگ رسم خواهند کرد.
